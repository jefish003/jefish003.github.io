Introduction to Control Systems

A control system consists of subsystems and processes (also known as plants) which are brought together for the explicit purpose of obtaining a desired output to within a desired performance under a given input. Control systems actually live all around us. For example, the cruise control on a car is a type of control system. Similarly, pacemakers are a type of control system used to help regulate the human heart. Standard drug delivery (think of when you take an aspirin for example) is another type of control system. Thus, it is clear that we have control systems which exist all around us.

There are a couple of major measurements of performance that we generally care about in control systems, one is the transient response, which is how the system responds before reaching a steady state (steady state being generally the asymptotic behavior of the system) and the other is the steady state error, which is the error between the desired steady state (as determined by the input) and the true steady state of the system.

There are two major types of control systems we will examine. One type is called an open-loop control system and the other is called a closed-loop control system. An open-loop control system is one in which the controller recieves the input and then directly applies control to the input, which runs through the process (or plant) which leads to the output. An open-loop system cannot adjust for any kind of disturbance, and thus is sensitive to outside disturbances, and thus to be effective there must be an accurate understanding or model for how the system will respond to the control. An example that we gave above of an open-loop control system is traditional drug delivery. When you take an aspirin, the aspirin directly dissolves in your blood, no matter how much pain you have, the entire thing will dissolve over some period of time. So the aspirin applies a control, but it cannot adjust or adapt to how much pain is in your system.

On the other hand, we have closed-loop control systems. These systems add a loop, typically which includes some kind of sensor, which allows the controller to adjust the controls to ensure the input plus the controlled signal are approaching the desired output state. An example of this is the pacemaker discussed above. The pacemaker sits inside the chambers of the heart and measures the hearts electrical activity, and compares that signal to a reference input (for instance perhaps a rate of 60 beats per minute), if the heartrate drops beneath that reference input, then the pacemakers battery powered generator fires off an electrical charge to help increase the rate.

Introduction to Analysis and Design of Control Systems

Analysis is the process by which a system's performance is determined. Design is the process by which a system's performance is created or changed. It should be noted that a control system is dynamic, that is, it responds to an input by undergoing a transient response before reaching a steady-state response which should resemble the input (or forcing). We should note that the transient response is quite important. For instance, in an elevator, a slow transient response (taking too long to start going) might make the person riding the elevator impatient, but too fast of a transient response might make the person feel queezy from too much acceleration.

As we should now understand from our introduction to differential equations, the steady-state response of the system should resemble the input. Recall for example, in the method of undetermined coefficients, we guessed that the particular solution looked like the input. This is the exact reason, the steady-state should in fact look like the input, at least for linear time invariant systems.
