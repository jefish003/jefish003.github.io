Consistent Estimators

We should start by a discussion of what we might view as desireable properties of estimators. There is no "general" way to choose the "best" model, and thus we must instead rely on heuristics. So now we will begin a discussion of some properties we might like an "ideal" estimator to have, though as we will find, these desireable properties cannot all be met by a single estimator.

An estimator is said to be consistent if that estimator eventually recovers the true parameters of the model that generated the data when the sample size goes to infinity. That is, $$\hat{\theta}(\mathcal{D}) \rightarrow \theta^*, \ \mbox{as} \ |\mathcal{D}| \rightarrow \infty,$$ where \(\mathcal{D}\) is the data. Or expressed in terms of probability, we can say, for every \(\epsilon > 0\), $$P(|\hat{\theta}_m - \theta|>\epsilon) \rightarrow 0, \ \mbox{as} \ m \rightarrow 0,$$ where \(m\) is the number of data points (for "weak consistency", we can get a stronger version of consistency if we allow convergence almost surely).
